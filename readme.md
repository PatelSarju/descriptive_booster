# 🏠 Analyzing Income Distribution and Household Demographics

## 📋 Project Overview
This project focuses on analyzing a dataset that includes household demographics, income levels, and education information. As a data analyst, you will work with these data points to explore different data types, apply statistical methods, and analyze the distribution properties, including skewness and kurtosis. 📊🔍

---

## 🔧 Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn) 🐍
- Excel or Google Sheets (Optional) 💻📊
- Statistical Analysis (Descriptive Statistics, Skewness, Kurtosis) 📈

---

## 🧑‍💻 Project Structure

### 📥 Dataset Information
The dataset should contain at least 150 records with the following columns:

- **Household_ID**: Categorical (Unique household identifier) 🏠
- **Age_of_Household_Head**: Numerical (Age of the head of household) 👨‍👩‍👧‍👦
- **Household_Income**: Numerical (Monthly income in local currency) 💸
- **Education_Level**: Categorical (Primary, Secondary, Graduate, Post-Graduate) 🎓
- **Family_Size**: Numerical (Total number of family members) 👨‍👩‍👧‍👦
- **Owns_House**: Categorical (Yes or No) 🏡
- **Urban_Rural**: Categorical (Urban or Rural) 🌆🌳

---

## 📑 Task List

### Part A: Theory & Definitions
1. **Data Types**: Define **Numerical** vs **Categorical** data. 🔢🔠
2. **Statistics**: Differentiate between **Descriptive** vs **Inferential** statistics. 📊📉
3. **Measures**: Explain **Mean**, **Median**, **Mode**, **Range**, **Variance**, **Standard Deviation**, **Skewness**, and **Kurtosis**. 🧮
4. **Distributions**: Explain **Gaussian Distribution**, **Log Normal Distribution**, **3-Sigma Rule**, **Percentiles**, and **Quartiles**. 📈📊

### Part B: Practical (using Python, Excel, or Google Sheets)
1. **Identify Data Types**: Categorize columns into **Categorical** and **Numerical**. 🗂️
2. **Central Tendency**:
   - Calculate **Mean**, **Median**, and **Mode** for **Household Income** and **Age**. 🔢
   - Interpret the central tendency. 📉
3. **Measures of Dispersion**:
   - Calculate **Range**, **Variance**, and **Standard Deviation** for **Household Income**. 📊
   - Find **Interquartile Range (IQR)** and comment on the spread of the data. 📈
4. **Distribution Analysis**:
   - Plot a **Histogram** for **Household Income**. 📊
   - Fit a **Gaussian Normal Distribution** curve. 📈
   - Calculate **Skewness** and **Kurtosis**. 📉📈
5. **Data Categorization**:
   - Visualize the relationship between **Income**, **Education Levels**, and **Urban/Rural** areas using **Boxplots** and **Histograms**. 📊📈
